# TABLE 21

TABLE 21은 PC 웹브라우저에서 혼자 플레이하는 카지노 스타일 블랙잭 게임입니다. 현금 가치가 없는 가상 게임머니만 사용하며 계정, 로그인, 백엔드, 결제 기능이 없습니다.

## 주요 기능

- 6덱 슈와 Web Crypto 기반 Fisher–Yates 셔플
- 딜러 S17, 블랙잭 3:2, HIT/STAND/DOUBLE/SPLIT/SURRENDER
- 딜러 A 오픈 카드의 INSURANCE와 플레이어 블랙잭의 EVEN MONEY
- 자유 플레이와 목표 자금 챌린지(쉬움 $5,000 / 보통 $10,000 / 어려움 $25,000)
- 진행 중 라운드, 카드 순서, 자금, 통계, 설정, 튜토리얼의 로컬 저장·복구
- 핸드 기준 통계와 라운드 기준 자금 그래프
- 7단계 첫 실행 가이드, 별도 게임 방법, 키보드 조작
- Web Audio로 생성하는 효과음·낮은 볼륨의 환경음
- 보통/빠르게/애니메이션 최소화 속도와 `prefers-reduced-motion` 지원
- 정적 프로덕션 빌드와 GitHub Pages 워크플로

## 빠른 실행 (Windows)

1. [Node.js LTS](https://nodejs.org/)를 설치합니다.
2. `run_game.bat`을 더블클릭합니다.
3. 최초 실행이면 npm 패키지를 설치한 뒤 브라우저에서 `http://127.0.0.1:5173`을 엽니다.
4. 열린 명령 프롬프트 창을 닫으면 로컬 서버가 종료됩니다.

Node.js 또는 npm이 없거나 패키지 설치에 실패하면 배치 파일이 한국어 안내를 표시하고 종료합니다. 이미 5173 포트를 다른 프로그램이 사용 중이면 해당 프로그램을 종료하거나 아래 npm 명령으로 다른 포트를 지정하세요.

브라우저를 열지 않고 실행 환경만 확인하려면 `run_game.bat --check`를 사용합니다.

```powershell
npm install
npm run dev -- --port 5174
```

## 조작

- 베팅: 금액 직접 입력, 빠른 추가 버튼, 이전 금액, 2배, 올인, 초기화
- `Enter`: 베팅 입력 중 베팅 확정
- `H`: HIT / 카드 받기
- `S`: STAND / 멈추기
- `D`: DOUBLE / 더블다운
- `P`: SPLIT / 스플릿
- `R`: SURRENDER / 서렌더
- `Space`: 현재 카드·정산 연출 즉시 완료
- `Tab`, `Shift+Tab`: 포커스 이동
- `Escape`: 올인 확인창 닫기

행동 버튼은 현재 상태에서 허용될 때만 활성화됩니다. 비활성 버튼에 마우스를 올리거나 포커스를 두면 제한 이유를 확인할 수 있습니다. 올인은 두 번 확인해야 확정됩니다.

## TABLE 21 V1 Standard

- 조커 없는 52장 카드 6덱을 사용합니다. 라운드 종료 시 슈가 75% 이상 소진되었으면 다음 라운드 전에 셔플합니다.
- 숫자 카드는 표시값, J/Q/K는 10, A는 1 또는 11입니다. 여러 A는 21을 넘지 않도록 필요한 만큼 1로 계산합니다.
- 딜러는 16 이하에서 HIT하고 모든 17(소프트 17 포함)에서 STAND합니다.
- 최초 두 장의 A + 10점 카드는 BLACKJACK입니다. 스플릿으로 만든 21은 일반 21입니다.
- 블랙잭은 3:2, 일반 승리는 1:1, PUSH는 원금 반환입니다. 딜러 블랙잭은 플레이어의 일반 21보다 우선합니다.
- DOUBLE은 최초 두 장에서 같은 금액을 추가하고 한 장만 받은 뒤 자동 STAND합니다.
- SPLIT은 같은 랭크만 허용합니다. 10/J/Q/K 혼합은 분할하지 않으며 최대 4개 핸드, A는 한 번만 분할합니다. 스플릿 A는 한 장씩만 받고 자동 STAND합니다.
- SURRENDER는 딜러 블랙잭 확인 뒤, 스플릿 전 최초 두 장에서만 가능하며 원래 베팅의 절반을 반환합니다.
- INSURANCE는 딜러 오픈 카드가 A일 때 기본 베팅 절반으로 선택하며 딜러 블랙잭이면 2:1 이익을 지급합니다.
- EVEN MONEY는 플레이어 블랙잭과 딜러 A 오픈 카드 조합에서 1:1 이익을 즉시 확정합니다.

모든 금액은 내부에서 정수 센트로 저장합니다. 3:2, 2:1, 절반 반환도 정수 분수 연산으로 계산하며 JavaScript 부동소수점 금액을 누적하지 않습니다.

## 모드

### 자유 플레이

- 최초 자금 $1,000, 최소 기본 베팅 $1
- 보유금 이내에서는 별도 테이블 최대 한도 없음
- 자유 플레이 자금은 챌린지를 플레이해도 별도로 보존
- 파산하면 $1,000으로 다시 시작하거나 로비로 이동

### 목표 자금 챌린지

- 모든 난이도에서 $1,000으로 시작하고 $0이면 실패
- 쉬움 $5,000 / 보통 $10,000 / 어려움 $25,000
- $1~$2,499: $10~$250
- $2,500~$7,499: $10~$500
- $7,500 이상: $10~$1,000
- 보유금이 $10 미만이면 남은 전액을 마지막 기본 베팅으로 허용
- 목표 판정은 스플릿을 포함한 모든 핸드 정산이 끝난 뒤 수행

## 저장과 복구

브라우저 `localStorage`의 `table21.snapshot.v1`에 다음 정보를 저장합니다.

- 스키마 버전, 설정, 튜토리얼 진행 상태
- 자유 플레이 자금과 현재 모드/챌린지 목표
- 진행 중 상태 머신 단계, 슈·버린 카드·딜러/플레이어 카드 순서
- 베팅, 스플릿 핸드, 활성 핸드, 보험, 딜러 확인, 정산 ID
- 누적 통계, 자금 기록, 최근 라운드

각 원자적 상태 전이 뒤 스냅샷을 저장하고 이전 정상 스냅샷을 백업 키에 보존합니다. 기본 스냅샷이 손상되면 백업을 검증해 복구합니다. 둘 다 사용할 수 없으면 안전한 초기 상태로 시작하고 화면에 오류를 알립니다. 정산 완료 라운드 ID를 저장해 새로고침 후에도 자금과 통계가 중복 적용되지 않습니다.

저장 데이터는 같은 브라우저와 같은 사이트 주소에서만 유지됩니다. 설정의 **모든 데이터 초기화**는 두 번 확인한 뒤 저장·통계·설정을 삭제합니다.

## 통계 정의

- 승·무·패와 블랙잭/버스트는 개별 핸드 기준입니다.
- 총 라운드와 자금 그래프는 최초 베팅 한 번부터 모든 스플릿 핸드 정산 완료까지를 한 라운드로 계산합니다.
- 더블다운, 스플릿, 보험은 시도·결과·손익을 별도 집계합니다.
- 챌린지는 성공, 실패, 중도 포기를 구분합니다.

런타임 상태 관리·차트 라이브러리는 사용하지 않습니다. React `useReducer`로 엔진 상태 전이를 명시하고 자금 그래프는 반응형 SVG로 직접 그립니다. 이미지, 폰트, 오디오 CDN에 의존하지 않으며 카드·칩은 CSS, 사운드는 Web Audio 합성으로 구현했습니다. 별도 제3자 시각·음원 에셋이 없어 `THIRD_PARTY_NOTICES.md`는 필요하지 않습니다.

## GitHub Pages

Vite의 `base`를 상대 경로 `./`로 설정해 저장소 이름 아래 경로에서도 에셋이 깨지지 않습니다. 화면 전환은 클라이언트 URL 라우팅을 사용하지 않으므로 직접 새로고침 404가 발생하지 않습니다.

저장소를 만든 뒤 다음 작업이 필요합니다.

1. 이 프로젝트를 GitHub 저장소의 기본 브랜치 `main`에 올립니다.
2. 저장소 **Settings → Pages → Source**에서 **GitHub Actions**를 선택합니다.
3. `Verify and deploy TABLE 21 to Pages` 워크플로를 수동 실행하거나 `main`에 push합니다.
4. 워크플로는 `npm ci` → `npm run verify` → `dist/` 업로드 → Pages 게시를 수행합니다.

현재 폴더에는 Git 저장소와 원격 URL이 없으므로 실제 커밋, push, Pages 게시는 수행하지 않았습니다. 워크플로와 정적 빌드까지만 준비된 상태입니다.
